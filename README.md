# DryNow

Flutter と OpenWeatherMap API を使用して、外干しできるかを判断し、乾燥時間を予測するアプリです。

Weather App v1で実装した現在天気の取得・表示を基盤として、DryNowへ発展させます。

## DryNow 開発フェーズ

```text
weather-app v1
      |
      v
weather-app-v1
      |
      v
Phase 1：気象データの信頼性検証
      |
      v
Phase 2：外干し判定
      |
      v
Phase 3：乾燥時間予測
      |
      v
Phase 4：UI改善
```

### Phase 1：気象データの信頼性検証

- 現在天気APIの取得値と表示内容を確認する
- 外干し判定に必要な気温・湿度・降水量・風速などのデータを整理する
- APIエラーや欠損値を安全に扱えるようにする

# 🔐 APIキー設定

プロジェクトルートに `.env` ファイルを作成します。

```env
OPENWEATHER_API_KEY=YOUR_API_KEY
```

`YOUR_API_KEY` を自分のOpenWeatherMap APIキーへ変更してください。

`.env` は `.gitignore` に登録されているため、GitHubには公開しません。
