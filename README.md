# DryNow

天気情報をもとに、**「今、洗濯物を外に干すべきか」**という判断を支援するFlutter製アプリケーション。

Flutterと外部APIの学習を目的として開発したWeather Appを基礎に、
気象情報を表示するだけでなく、**ユーザーの具体的な行動判断につなげるアプリ**を目指してDryNowとして開発を進めている。

> 現在開発中

---

## DryNowでの目標

一般的な天気アプリでは、気温・湿度・降水量・風速などの気象情報を確認できる。

DryNowでは、それらのデータを利用して、

* 今、外干しできるか
* 洗濯物がどの程度乾きやすいか
* 乾燥までどれくらいの時間がかかりそうか
* 外干しするならどの時間帯が適しているか

といった、**洗濯に関する意思決定まで支援すること**を目標とする。

---

## 📌 開発の経緯

本プロジェクトは、Flutterと外部APIを利用したアプリ開発の学習として制作したWeather Appからスタートした。

Weather Appでは、OpenWeather APIを利用した気象データの取得や、Flutter上での表示、エラー処理などを実装。

その後、

**「天気情報を表示するだけではなく、その情報を具体的な行動につなげられないか」**

と考え、洗濯物の外干し判断を支援するDryNowへ発展させることにした。

Weather Appとしての完成時点は、Gitタグ **`weather-app-v1`** として保存している。

## 🚧 現在の開発フェーズ

### Phase 1：気象データの信頼性検証

DryNowでは、取得した気象データをもとに外干し判定や乾燥時間予測を行う。

そのため、判定アルゴリズムを実装する前に、**入力となる気象データがDryNowで利用できる精度か検証する**。

主な検証項目：

* 気温
* 湿度
* 降水量
* 風速
* データ取得地点
* データ更新時刻
* 都市名指定と緯度・経度指定による違い

必要に応じて取得方法やデータソースの変更も検討する。

## 🗺 Development Roadmap

### Phase 1：気象データの信頼性検証 ← 現在

* APIレスポンスの確認
* 取得地点・更新時刻の確認
* 他の気象情報との比較
* 緯度・経度を利用した取得方法の検討

### Phase 2：外干し判定

気温・湿度・風速・降水量などを利用し、外干しに適しているかを判定するロジックを実装する。

### Phase 3：乾燥時間予測

気象条件や洗濯物の条件から、乾燥までに必要な時間を推定するアルゴリズムを検討・実装する。

### Phase 4：UI / UX改善

* 判定結果の分かりやすい表示
* 現在地への対応
* 時間帯ごとの予測
* 外干しに適した時間帯の表示
